# sizucu-links

しずくグループの「作ったサイト＋開発サービス」への入口リンク集ページ。

- 公開URL: https://ph2144tt0609-cmyk.github.io/sizucu-links/
- `index.html` はローカルの生成ツールが正本（マイドライブの `CLAUDE.md` の公開サイト表）から自動生成する。手で編集しない。
- `noindex` 設定（検索には出さない）。合言葉制の内部ツールは掲載しない。

## 更新のしかた

公開サイトが増えた／URLが変わったら、いつも通り `CLAUDE.md` の「公開済みサイト一覧」表を直す。
そのあと、このフォルダの `公開.bat` をダブルクリックするだけ（再生成 → git push）。
ブックマークは常にこの1つのURLだけでよく、登録し直しは不要。

※ 生成ツール（`build.py` / `公開.bat`）はローカル限定（`.gitignore` 除外）。
